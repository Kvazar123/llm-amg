- **Развилки, согласованные с пользователем:**
  - **Игнор по намерениям** — параллельные ключи `mirror_exclude`/`absorb_exclude` (+ глобальный `exclude`). `.gitignore`: **явный источник важнее** (корень mirror/absorb в `.gitignore` → всё равно индексируется; мусор глубже — фильтруется); флаг `respect_gitignore` (умолчание true; false = из конфига, без git). `DEFAULT_IGNORE_DIRS` — жёсткий, неприкосновенен для каталога агента.
  - **Установщик `install.py`** — неинтерактивный, опирается на конфиг/флаги; вопросы задаёт **МОДЕЛЬ**. **НЕ активирует молча и НЕ строит граф**, спрашивает; по согласию пишет `active`. Предлагает также `--build` (структурный bootstrap сразу). **`/amg on` ≠ индексация** — только флаг; граф строит петля (новая сессия), `/amg sync` или словесный триггер «построй/синхронизируй граф».
  - **Reinstall безопасен** (особенно global): обновляются только `amg-*` (чужие скиллы целы), блок меняется между маркерами, существующий конфиг не затирается, локальные графы не трогаются. `--project-only` — добавить проект к глобальной установке (только локальный конфиг). **Uninstall** — `--uninstall [--scope global] [--purge-graph]`.
